# access2mysql: Import MS Access databases to MySQL

### Syntax

```
access2mysql.sh [-s] [-o] [-r] [-f pathAndAccessFileName] [-d mysqlDbName] [-u mysqlUserName] [-p mysqlPwd]
```

### Example (load Teck DB)

```
access2mysql.sh -f VegModel_20190108.mdb -d teck_VegetationModel_20190108 -u bboyle -p 5ten0cereu5
```

### Notes
1. Path: /Users/bboyle/bin/
